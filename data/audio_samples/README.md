# Audio Samples

Place short local STT demo files here when running the audio integration manually.

Recommended mock sample names:

- `explain_this.wav`
- `right_figure.wav`
- `meaning_this_figure.wav`
- `summarize_slide.wav`
- `quiz_concept.wav`

Real recordings and downloaded model files should stay local and are ignored by git.
The mock engine maps these filenames to deterministic Chinese transcripts, so the
default unit tests and mock demos do not require real audio files.
